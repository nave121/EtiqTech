# Canonical protocol schema — the integration contract

`https://navina.dev/iacuc.schema.v2.json` · JSON Schema draft-07 · generated by `scripts/gen_schema_doc.py` from `src/schema.py` (do not edit by hand).

This JSON object is what every ingest adapter produces and what the deterministic linter and the LLM layers consume. An institution with a different protocol system writes an adapter that emits this shape (see `docs/adapters.md`); it never has to read the HTML parser. Send it as a `.json` upload or as `{"instance": {...}}` to `/api/analyze`; it is validated strictly against this schema on the way in.

Top-level required blocks: `header`, `research`, `pi`, `participants`, `summaries`, `alternatives_search`, `animals_total`, `n_justification`, `experiments`, `pi_declaration`.
