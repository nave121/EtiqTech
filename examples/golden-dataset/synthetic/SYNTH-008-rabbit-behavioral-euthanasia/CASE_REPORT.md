# Case SYNTH-008 - Rabbit Behavioral Habituation

## Summary
- Adult rabbit behavioral habituation protocol with terminal tissue collection.
- The bad variant uses cervical dislocation on a 1.4 kg rabbit without documenting any required conditions.

## Main Problem In The Bad Variant
- Cervical dislocation exceeds the AVMA weight limit for rabbits and should not be used for this animal size.
- The protocol also omits any documentation that would satisfy conditionally acceptable euthanasia requirements.

## Good Variant Fix
- Switch to pentobarbital overdose after deep anesthesia.
- Keep the behavioral design unchanged so the regression isolates the euthanasia correction.
