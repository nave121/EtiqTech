# Case SYNTH-009 - Zebrafish Pharmacology

## Summary
- Adult zebrafish pharmacology protocol with terminal tissue collection.
- The bad variant uses CO2 despite zebrafish requiring species-appropriate aquatic euthanasia methods.

## Main Problem In The Bad Variant
- CO2 is unacceptable for zebrafish under the AVMA species-method matrix.
- The bad variant includes otherwise complete euthanasia details so the regression isolates the species-method prohibition.

## Good Variant Fix

- Keep animal numbers, monitoring, and endpoints unchanged so the regression is focused on euthanasia compliance.
